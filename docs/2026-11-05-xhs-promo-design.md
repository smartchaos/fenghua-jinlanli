# 小红书推介素材设计 — 2026-11-05

## 意图与目的

为 https://smartchaos.github.io/fenghua-jinlanli/ （风华锦澜里业主入群 3D 可视化）制作小红书笔记图片素材。目标读者：本小区业主。转化目标：业主访问网站、评论/私信楼号、加入业主群。

已确认决策：
- 受众：招募小区业主入群（非技术圈秀作品）
- 引流：不放微信群二维码；尾页放网址 + 引导评论/私信
- 形式：纯图片 8 张轮播，不做视频
- 风格：真实 3D 场景截图做底 + 小红书排版（大字标题、短句、贴纸标签），不用 AI 生成图

## 目标 / 非目标 / 反目标

- 目标：8 张 3:4（1242×1660）可直接发布的 PNG；一套配套笔记标题与正文文案。
- 非目标：不改网站本身；不生成视频；不做 AI 插画。
- 反目标：图中出现微信群二维码（平台导流违规）；特写镜头可读出家人级隐私信息；文案中出现"加群"等敏感词堆砌。

## 制作方式（builder 自行决定项）

- headless Chrome（puppeteer-core + chrome-headless-shell，本机已装）打开 model.html，`window.__MODEL` 脚本化摆机位；viewport 1242×1660、dsf=2 截图再缩放，保证文字边缘锐利。
- 按需渲染坑：截图前强制 `needsRender` 并重等 RAF（闲置停绘状态直接截图会拿到旧帧）。
- 排版合成：HTML/CSS 模板叠加文字与贴纸标签，同管线渲染出终稿 PNG。
- 产出目录：`marketing/xhs/`（raw/ 底图 + final/ 终稿 + copy.md 文案）。

## 风险

- 平台规则：图片含网址属灰区但常见可过；若被限流，删尾页网址、只留评论区引导即可（尾页排版预留可删版本）。
- 数据时效：P6 报表截图带生成日期水印式小字，避免"旧数据"误导。
